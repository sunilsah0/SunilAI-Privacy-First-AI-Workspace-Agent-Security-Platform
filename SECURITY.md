# Security policy

SunilAI is a learning project and has **not** been independently audited.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it, and what data or access it exposes.

## Supported versions

Only the latest commit on `main` is supported.

## What helps most

- Cross-user or cross-organization data access (these are the most serious issues for this project).
- Ways to make the AI trigger an action the policy engine should refuse.
- Ways to make the app contact the internet while offline mode is on.
